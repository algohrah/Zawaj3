# خطة إعادة هيكلة رحلة التوافق والدفع عبر الواتساب

إعادة تنظيم وتطوير رحلة التوافق لتصبح رحلة ميسّرة وواضحة ترتكز على ٣ مراحل رئيسية، مع تحويل مسار الدفع ليتم عبر محادثة واتساب الرسمية المباشرة برقم الطلب وبيانات الطرفين، وتمكين الإدارة من إدخال المبالغ المدفوعة بدقة وتحديد مصير الطلب النهائي.

---

## مراجعة المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> بناءً على إجاباتكم الكريمة في المرحلة السابقة، تم اعتماد المعايير التالية كركائز أساسية للخطة:
> - **هيكل الأتعاب المعتمد**: إجمالي الأتعاب **5,000 ريال قطري**، وعربون الجدية المبدئي **1,000 ريال قطري**.
> - **حساب المتبقي وسجل الأطراف**: تسجيل مدفوعات كل طرف بشكل مستقل عبر لوحة الإدارة (يمكن إدخال من 0 إلى أي مبلغ)، وحساب المتبقي تلقائياً (`المتبقي = 5000 - المبلغ المدفوع`).
> - **آلية التنسيق والتواصل**: يتم التنسيق بالكامل عبر إدارة المنصة على الواتساب بسرية تامة دون كشف مباشر للأرقام على الموقع، ويظهر للمشتركين شارة ورسالة واضحة: «جاري التنسيق بين الأطراف».
> - **خيارات الإدارة الحاسمة**: خياران واضحان للنتيجة النهائية للرحلة:
>   1. **حدث نصيب وتم تسليم المهر** (اكتمال مبارك وتوثيق الرحلة بنجاح).
>   2. **لم يحدث نصيب** (إلغاء الطلب وإنهاء الرحلة باحترام وقسمة ونصيب).

## 1. نظرة عامة وتجربة المستخدم الجديدة (3 مراحل رئيسية)

### المراحل الثلاث للمستخدم:
1. **المرحلة الأولى: إرسال الطلب (بانتظار القبول)**
   - يقوم العضو بإرسال طلب التوافق للطرف الآخر.
   - تظهر حالة الطلب لدى المرسل: «بانتظار رد الطرف الآخر».
   - تظهر لدى المستقبل خيارات: «قبول مبدئي» أو «اعتذار بلطف».

2. **المرحلة الثانية: القبول المبدئي والدفع عبر الواتساب**
   - بمجرد قبول الطلب، ينتقل الطلب لمرحلة الدفع.
   - يظهر لكل طرف بطاقة دفع مخصصة وواضحة تحتوي على:
     - رقم الطلب (Request ID).
     - المعرّف / الاسم المستعار للعضو الحالي.
     - المعرّف / الاسم المستعار للطرف الآخر.
     - مبلغ العربون المطلوب (1,000 ر.ق من إجمالي 5,000 ر.ق).
   - زر بارز ومباشر: **«ادفع عبر الواتساب برقم الطلب»**
     - عند النقر، يفتح تطبيق الواتساب مباشرة برقم الإدارة الرسمي (`+974 5562 0331`) مع رسالة جاهزة منسقة تتضمن (رقم الطلب + معرّف العضو + معرّف الطرف الآخر + طلب تأكيد سداد العربون).
   - حالة الانتظار: «بانتظار مراجعة وتأكيد الإدارة للسداد».

3. **المرحلة الثالثة: جاري التنسيق والتواصل (تحت إشراف الإدارة)**
   - بعد قيام الإدارة بتأكيد دفع العربون، ينتقل الطلب مباشرة إلى هذه المرحلة.
   - تظهر للطرفين شاشة أنيقة وواضحة تفيد بأن: «جاري التنسيق بين الأطراف بواسطة إدارة المنصة».
   - يظهر للمشترك ملخص مالي واضح:
     - المبلغ المدفوع حتى الآن.
     - المتبقي من إجمالي الأتعاب (من أصل 5,000 ر.ق).
   - يتم التنسيق وتحديد المقابلات الشرعية عبر الواتساب تحت إشراف الإدارة.

4. **المسار الختامي (قرارات الإدارة):**
   - **حدث نصيب وتم تسليم المهر**: توثيق نجاح الزواج واكتمال الرحلة، واحتساب سداد باقي الأتعاب.
   - **لم يحدث نصيب**: أرشفة الطلب كملغى باحترام.

## 2. لوحة الإدارة وإدارة المدفوعات والرحلات

تحديث واجهة إدارة الطلبات (`AdminRequests.tsx`) لتوفر للإدارة الآتي:
- **تسجيل مالي مرن لكل طرف**:
  - حقل إدخال مبلغ سداد للمرسل (من 0 إلى أي مبلغ).
  - حقل إدخال مبلغ سداد للمستقبل (من 0 إلى أي مبلغ).
  - إمكانية تحديد إجمالي الأتعاب الافتراضي 5000 ر.ق أو تعديله، وحساب المتبقي تلقائياً.
- **أزرار نقل المراحل بضغطة زر**:
  - اعتماد سداد العربون ونقل الطلب فوراً إلى «جاري التنسيق والتواصل».
  - زر حاسم بلون زمردي: **«حدث نصيب وتم تسليم المهر»** (تحويل الحالة إلى مكتمل بنجاح).
  - زر حاسم بلون رمادي/وردي: **«لم يحدث نصيب (إلغاء الطلب)»** (تحويل الحالة إلى ملغى).
- **إرسال رسائل وإشعارات تلقائية** للمشتركين عند كل تغيير في الحالة.

## 4. خطة التعديلات البرمجية التفصيلية

1. **تحديث ثوابت ونصوص الرحلة (`src/lib/journey.ts`)**:
   - اختصار `JOURNEY_STAGES` وتعديل أسماء ومفاهيم المراحل إلى:
     - `sent` (بانتظار الرد)
     - `accepted` (القبول وسداد العربون عبر الواتساب)
     - `coordination` (جاري التنسيق بين الأطراف)
     - `completed` (حدث نصيب وتم تسليم المهر)
     - `cancelled` (لم يحدث نصيب / ملغى)
   - إضافة نصوص التوجيه وحساب المبالغ (إجمالي 5000 ر.ق، العربون 1000 ر.ق).

2. **تحديث صفحة رحلة الطلب للمستخدم (`src/pages/JourneyPage.tsx`)**:
   - إزالة بوابات الدفع الإلكترونية السابقة واستبدالها بزر مباشر:
     `https://wa.me/97455620331?text=...` محمل بنص الرسالة الدقيق:
     `السلام عليكم، أود سداد عربون طلب التوافق رقم: #... | يوزري: ... | يوزر الطرف الآخر: ...`
   - عرض بطاقة مالية نظيفة توضح: المبلغ المسدد، المتبقي من الأتعاب، وإجمالي الأتعاب (5,000 ر.ق).
   - عرض حالة «جاري التنسيق بين الأطراف بواسطة إدارة المنصة» في مرحلة التنسيق.

3. **تحديث صفحة الطلبات للمستخدم (`src/pages/InterestRequests.tsx`)**:
   - تبسيط بطاقات الطلبات وإظهار زر الدفع عبر الواتساب للمرحلة الثانية.
   - تبسيط دليل المراحل (Legend) والمؤشرات لتعكس المراحل الثلاث.

4. **تحديث لوحة تحكم الإدارة (`src/pages/admin/AdminRequests.tsx`)**:
   - إضافة واجهة تحكم بالمدفوعات للأطراف:
     - حقل رقمي لتسجيل المبلغ المسدد للمرسل (مع المتبقي التلقائي).
     - حقل رقمي لتسجيل المبلغ المسدد للمستقبل (مع المتبقي التلقائي).
   - أزرار حاسمة وسريعة:
     - نقل إلى «جاري التنسيق والتواصل».
     - اعتماد «حدث نصيب وتم تسليم المهر».
     - تسجيل «لم يحدث نصيب».

5. **تحديث طبقة البيانات ونموذج الطلب (`src/lib/types.ts` & LocalStore)**:
   - التأكد من تخزين `total_fee: 5000` و `deposit_amount: 1000` و `sender_paid_amount` و `receiver_paid_amount`.
